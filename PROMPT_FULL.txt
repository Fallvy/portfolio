### 3. 3D Сцена (Three.js)

**Центральный артефакт**:
- Геометрия: IcosahedronGeometry(1, 1)
- Материал: ShaderMaterial с GLSL шейдерами
- Эффекты:
  - Vertex displacement для "жидкого" эффекта
  - Fresnel для края объекта
  - Внутреннее свечение (AdditiveBlending)
  - Wireframe overlay (прозрачность 0.3)

**Шейдеры**:
```glsl
// Vertex Shader
uniform float time;
varying vec3 vNormal;
varying vec3 vPosition;

void main() {
    vNormal = normalize(normalMatrix * normal);
    vPosition = position;

    vec3 newPos = position;
    float displacement = sin(position.x * 2.0 + time) * 
                        sin(position.y * 2.0 + time) * 
                        sin(position.z * 2.0 + time) * 0.1;
    newPos += normal * displacement;

    gl_Position = projectionMatrix * modelViewMatrix * vec4(newPos, 1.0);
}

// Fragment Shader
uniform float time;
uniform vec3 color1; // #00F0FF
uniform vec3 color2; // #BD00FF
varying vec3 vNormal;
varying vec3 vPosition;

void main() {
    vec3 viewDirection = normalize(cameraPosition - vPosition);
    float fresnel = dot(viewDirection, vNormal);
    fresnel = clamp(1.0 - fresnel, 0.0, 1.0);
    fresnel = pow(fresnel, 2.0);

    vec3 color = mix(color1, color2, fresnel);
    float glow = sin(time + vPosition.x * 2.0) * 0.5 + 0.5;
    color += color1 * glow * 0.3;

    gl_FragColor = vec4(color, 0.9);
}
```

**Астероиды (навигация)**:
- 4 объекта: DodecahedronGeometry(0.3, 0)
- Материал: MeshStandardMaterial (цвет #1a1a2e, roughness 0.8)
- Внутреннее свечение: сфера с AdditiveBlending
- Позиции:
  - HOME: top: 10%, left: 50%
  - PROJECTS: top: 50%, right: 10%
  - LABORATORY: bottom: 10%, left: 50%
  - CONTACT: top: 50%, left: 10%

**Частицы**:
- 500 частиц в буферной геометрии
- Цвета: градиент cyan→purple
- Анимация: медленное вращение и движение по синусоиде

**Освещение**:
- AmbientLight: 0x404040, интенсивность 0.5
- DirectionalLight: 0x00F0FF, позиция (5, 5, 5), тени включены
- PointLight (фиолетовый): 0xBD00FF, позиция (-3, 2, 3)
- PointLight (зелёный): 0x39FF14, позиция (3, -2, 2)

**Камера**:
- PerspectiveCamera: FOV 75, near 0.1, far 1000
- Позиция: z = 5 (изменяется при скролле 2-10)
- Реагирует на движение мыши (lerp 0.02)

## Performance optimization

### Рекомендации
1. **LOD (Level of Detail)**: уменьшать детализацию на расстоянии
2. **InstancedMesh**: для рендеринга множества частиц
3. **Texture compression**: KTX2/Basis формат
4. **Lazy loading**: загрузка по требованию
5. **Debounced resize**: оптимизация обработки resize

### Целевые показатели
- 60 FPS на современных GPU
- Загрузка < 3 секунд
- Lighthouse score > 90
